# ARS Distributors V1.0.0 — Pilot release notes

**Publisher:** RS Nextward  
**Channel:** Shop-opening pilot  
**Status:** Draft / unreleased

## Overview

A local-first wholesale distribution management system targeting Windows and Linux Mint Cinnamon. The pilot combines sales, stock, purchasing, accounts and business administration with local PostgreSQL storage.

## Highlights

- Box/Piece inventory and wholesale billing, quotations and customer credit.
- Import and warehouse workflows, supplier accounts and landed-cost management.
- Financial, payroll and partner management workflows.
- 24 × 27 cm invoice layout and business report exports.
- Desktop setup, maintenance, verified local backup and encrypted cloud backup support.
- Signed update preparation and isolated recovery rehearsals.

## Installation

Use pilot CI artifacts only on disposable or explicitly authorized test installations. Follow the repository README and V1.0 acceptance record. Never overwrite existing runtime data or database volumes during installation.

## Known limitations

Physical Windows and Mint installation, real printer testing, financial reconciliation, target-machine encrypted backup configuration and full disaster recovery acceptance remain outstanding. Live update activation is not approved.
