HARDWARE SHOP POS - QUICK USE

START SYSTEM
1) Double-click: Hardware Shop POS
2) Wait for browser to open
3) Use the system normally

IMPORTANT
- Keep the black window open while working.
- Do not close that window during shop time.

STOP SYSTEM
1) Double-click: Stop Hardware Shop POS
2) Press any key when asked

IF SOMETHING GOES WRONG
- Close all POS windows
- Double-click Hardware Shop POS again
- If still not working, call support
